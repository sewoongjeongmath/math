# 정세웅의 수학세상

이 저장소에 올린 폴더와 파일이 그대로 사이트에 나타납니다. 파일을 올리고 1~2분쯤 지나면 사이트에 반영돼요.

## 자료 올리기

1. 올릴 폴더(예: `중1`)로 들어갑니다.
2. **Add file → Upload files**를 누르고 파일을 끌어다 놓습니다.
   - 폴더째 끌어다 놓으면 하위 폴더까지 그대로 올라갑니다.
3. 맨 아래 **Commit changes**를 누릅니다.

## 링크 올리기

1. 폴더 안에서 **Add file → Create new file**을 누릅니다.
2. 파일 이름을 `제목.url`로 짓습니다. 예: `일차방정식 퀴즈.url`
3. 내용 칸에 주소를 한 줄로 붙여 넣고 **Commit changes**를 누릅니다.

## 새 폴더 만들기

**Add file → Create new file**의 파일 이름 칸에 `중1/1학기/.gitkeep`처럼 슬래시(`/`)를 넣어 쓰면 폴더가 생깁니다.
(그냥 하위 폴더째 업로드해도 됩니다.)

## 알아두면 좋은 것

- `.html` 파일은 HTML 자료(▶ 실행 / ⬇ 받기), `.url` 파일은 링크(↗ 열기)로 보입니다. PDF, 이미지 같은 다른 파일도 올릴 수 있습니다(↗ 열기 / ⬇ 받기).
- 사이트에 보이는 이름은 파일 이름에서 확장자를 뺀 것입니다.
- 이름이 `.` 또는 `_`로 시작하는 파일과 폴더는 사이트에 보이지 않습니다.
- 첫 화면의 폴더 순서와 사이트 제목은 `site.json`에서 바꿀 수 있습니다.
- 지우려면 파일을 열고 오른쪽 위 `…` 메뉴에서 **Delete file**을 누릅니다.
- 파일 하나는 25MB까지 웹에서 올릴 수 있습니다.
